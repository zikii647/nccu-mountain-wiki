# 行前安全檢核清單（Safety Audit Checklist）

> [!NOTE]
> 本清單供 **Ingest 階段檢核過往計畫書缺漏** 與 **Query 階段新計畫書安全健檢** 使用。已整合政大登山隊高嚮訓練課規範（[政大登山隊開隊規定、隊伍管理與知識累積](../guides/club-leadership-and-team-management.md)、[登山計畫書撰寫與行前準備 SOP](../guides/trip-planning-sop.md)），後續匯入各隊檢討將持續更新。

## 0. 社團開隊資格、分級與隊伍組成（政大登山隊基準）
- [ ] **隊伍分級與領隊資格**：確認路線屬 D（≤3天）／C（3–5天，或≤3天含危險地形）／B（6–8天）／A（≥9天）級，領隊／預備領隊未越級；預備領隊開過夜隊須配輔領（或符 2 次過夜經驗＋安委一致同意獨立開 D 級過夜隊）（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.23`）。
- [ ] **籌備時程與禁止臨時改線**：至少提前 1 個月開始籌備；若因天候取消原線，嚴禁在未重新做好完整圖資與撤退規劃下倉促改線（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.23, P.26`）。
- [ ] **人數與新舊比**：人數最好不超過 20 人；新舊比符合「新生隊 2:1、其他隊 1:1」（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.24`）。
- [ ] **標準行進順序與決策機制**：隊形安排為「嚮導 → 想培育／走慢者 → 能顧人幹部 → 新舊交錯 → 領隊與資深幹部分走中／後」，決策經幹部討論後由領隊／輔領最終拍板（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.24`）。

## 1. 行程與時間控管
- [ ] **每日行程表完整**：標明到登山口交通、起床／出發／休息／午餐／到營地時間、高度變化與里程數（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.15`）。
- [ ] **參考紀錄相似性與係數**：是否蒐集「資訊完整且行程相似」的紀錄，並區分輕重裝、不同植被與地形之速度（嚴禁拿單人快腳或騎車紀錄套用大隊）（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.15`）。
- [ ] **D0 與高度適應**：高海拔行程是否規劃 D0 或控制 D1 不過度疲勞，降低高山症與摸黑風險（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.10`）。
- [ ] **摸黑風險與關門時間**：是否標註日出日落時間、預留緩衝、訂定最晚折返（關門）時間與預備天。

## 2. 撤退、易迷途與緊急應變
- [ ] **逐日撤退計畫**：長天數行程是否**每天**皆以時間、易出事地點為分際規劃安全下山路線（含溪水暴漲等量化分際，如水深及腰撤退）（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.18–19`）。
- [ ] **行程調整與易迷途路段**：單攻／拆隊調整情境是否寫清；是否條列「易迷途路段」與正確辨識特徵、確認腰繞崩塌與大雨後風險（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.16, P.18–19`）。
- [ ] **天候判讀與取消／延期標準**：颱風、豪雨、低溫降雪、地震後封山之開隊倒隊條件。
- [ ] **山難、高山症、失溫與待援原則**：推定任何症狀為高山症並以下撤為核心；失溫即時避風換乾衣補熱量；迷途不擅自下溪谷；**爛天氣切勿於裸露稜線久等直升機**（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.6–10, P.28`）。

## 3. 留守與通訊機制
- [ ] **留守人制度**：明確指定留守人、每日定時回報時段、最晚回報死線與逾時通報流程（*Wiki 中不留留守人電話，但須確認計畫書有落實機制*）。
- [ ] **通訊與無線電管理**：標註手機訊號點、衛星通訊（如 inReach）或團隊無線電**主頻／備頻**與**備用電池**配置。
- [ ] **離線地圖與紙本地判**：比對多種圖資（如經建三與 OSM／魯地圖），備妥離線軌跡、行動電源與紙本地判能力（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.6`）。

## 4. 水源、營地與糧食
- [ ] **水源計畫與背水量**：列出**每天可取水點與穩定度**、缺水因應方案、以及背水日之**公水＋私水**總量估算（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.20`）。
- [ ] **營地與山屋確認**：床位中籤／營地申請、腹地與避風性；**高山不可只攜帶外帳**（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.21, P.28`）。
- [ ] **預備糧與菜單合理性**：對應預備天備妥足量免煮／易煮預備糧；菜單營養方便少廚餘、長天數後期份量適度增加，避免過度繁複拉長炊煮時間（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.20`）。

## 5. 裝備、體訓與人員評估
- [ ] **實體裝備檢查（特別是保暖衣物與公裝）**：私裝最易出問題為**保暖衣物**，秋冬／冬季須將毛帽、保暖手套、中層與備用乾衣列為必帶並實際檢查；出發前點交公裝爐頭／瓦斯／擋風板（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.21`）。
- [ ] **特殊地形／生物／醫藥裝備**：依行程備妥技術安全裝備、對應醫藥與急救包（含抗組織胺、硬蜱拔除器、熟悉草刀與爐具安全）（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.9, P.11`）。
- [ ] **體訓與隊員參與**：確認隊員體能、高山經驗史，並確保「隊員皆瞭解行程與風險，不只當跟屁蟲」（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.10, P.17`）。

## 6. 法規、保險與交通
- [ ] **入園證／入山證與身分證件**：申請時程、補件期限與山屋核對用證件。
- [ ] **登山綜合保險**：確認涵蓋緊急救援費用。
- [ ] **交通接駁與備案**：去回程接駁與下山撤退備用方案。
