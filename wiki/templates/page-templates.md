# Wiki 頁面標準範本

本頁定義 `trips/`、`guides/`、`lessons/` 三類頁面的標準欄位與段落骨架，確保全站格式一致且符合標準 Markdown 相容性。

---

## 1. 出隊檔案範本（`wiki/trips/<slug>.md`）

```markdown
---
title: <隊伍／路線名稱>
type: trip
date: YYYY-MM-DD  # 或 YYYY-MM，未知填 unknown
days: <天數>
region: <山域／國家公園，如：雪霸國家公園>
status: <已完成 / 撤退 / 計畫中>
sources:
  - <原始檔名 1>
  - <原始檔名 2>
tags: []
updated: YYYY-MM-DD
---

# <隊伍／路線名稱>

## 1. 基本資訊與路線摘要
- **出隊日期**：（來源：檔名｜章節）
- **隊伍人數與分工**：僅留姓名／暱稱，移除所有聯絡方式與個資（來源：檔名｜章節）
- **路線與 GPX 摘要**：起終點、總距離、總爬升／下降、關鍵航點（來源：檔名｜章節或 GPX）
- **交通與入山入園**：（來源：檔名｜章節）

## 2. 行程對照（預計 vs. 實際）
| 天數 | 預計行程與時間（來源） | 實際紀錄與時間（來源） | 落差與備註 |
| :--- | :--- | :--- | :--- |
| D1 | ... | ... | ... |

## 3. 水源、營地與路況紀錄
> 若與其他隊伍／年份記載矛盾，須並陳雙方日期與來源，不覆蓋舊紀錄，並標註以最新紀錄優先參考。

## 4. 菜單、體訓與財務結算摘要
- **菜單與公糧重點**：（來源：菜單檔名｜分頁）
- **體訓要求與執行**：（來源：體訓檔名｜分頁）
- **財務結算摘要**：總費用／人均／主要開銷，不含匯款帳號（來源：結算檔名｜分頁）

## 5. 該次檢討與避坑重點
- 條列該次檢討報告重點（來源：檢討檔名｜章節），並連結至對應跨隊主題頁，如 `[糧食與菜單踩坑](../lessons/food-and-menu-pitfalls.md)`。

## 6. 安全檢核與 AI 提醒
> [!WARNING] AI 安全提醒／待補齊
> 依 [行前安全檢核清單](../templates/safety-audit-checklist.md) 列出本隊計畫書缺漏或潛在風險項目（明確區分「原始記載」與「AI 建議」）。
```

## 2. 領隊實務與 SOP 範本（`wiki/guides/<slug>.md`）

```markdown
---
title: <實務主題名稱>
type: guide
sources:
  - <原始檔名>
tags: []
updated: YYYY-MM-DD
---

# <實務主題名稱>

## 1. 核心原則與適用情境
- 簡述本規範的目的與適用階段（籌備／行前／行進／撤退／結算）。

## 2. 實務重點與標準做法
- 逐項整理來源規範，關鍵數字與規定須註明 `（來源：檔名｜章節）`。

## 3. 常見誤區與相關檢討案例
- 連結至 `../lessons/` 或 `../trips/` 的實際案例。

## 4. AI 安全補充（選填）
> [!TIP] AI 安全提醒／延伸建議
> 若來源未涵蓋但對台灣登山安全至關重要的項目，在此補充並與原文明確區隔。
```
