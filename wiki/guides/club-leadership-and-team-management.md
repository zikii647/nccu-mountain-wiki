# 政大登山隊開隊規定、隊伍管理與知識累積

> 本頁整理自政大登山隊高嚮訓練課講義（講者：黃子豪，2023/05/10；來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.22–31`）。

## 1. 政大登山隊開隊規定（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.23`）

### 1.1 山岳隊伍分級
| 級別 | 定義標準 |
| :--- | :--- |
| **D 級** | 活動天數 **3 天以下**之路線。 |
| **C 級** | 活動天數 **3 至 5 天**之路線，或活動天數 **3 天以下但有危險地形**之路線。 |
| **B 級** | 活動天數 **6 天至 8 天**之路線。 |
| **A 級** | 活動天數 **9 日以上**之路線。 |

### 1.2 開隊資格與輔領規範
- **誰能開隊**：**領隊及預備領隊**；非具有領隊或預備領隊資格者，不得開隊。
- **能開什麼隊**：依自身帶隊經驗安排合適之隊伍行程，**不得越級**。
- **預備領隊開隊限制**：
  - 原則上**必須有一位輔領協助**，且**僅可帶 D 級與 C 級之隊伍**。
  - 輔領資格：由具本隊領隊資格，或經領隊會議認可之畢業校友擔任。
  - **例外（免輔領情形）**：
    1. 開**一日山岳活動**。
    2. 已有 **2 次以上過夜隊**的帶隊經驗，並經**安全委員一致同意**後，可獨立開 **D 級過夜隊**。
- **籌備時程**：**一個月前就要開始準備開隊工作**。

## 2. 隊伍管理原則（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.24`）
> [!NOTE]
> 原始投影片 P.24 與 P.25 內容完全重複，皆為本節隊伍管理規範。

- **人數上限**：無絕對標準，通常依**交通方式、營位、幹部比**設定，但**最好不要超過 20 人**。
- **新舊比設定**：
  - **新生隊伍**：`2:1`（新：舊）
  - **其他隊伍**：`1:1`（新：舊）
- **標準行進順序**：
  `嚮導` → `想培育的人／走得慢的` → `能顧人的幹部` → `新舊交錯` → `領隊與另一個資深幹部分別走在中間跟最後`
- **決策機制**：幹部（特別是有領隊資格者）提出意見，與隊伍領隊討論後，**最終由領隊或輔領決定**。
- **額外提醒**：**「帶朋友、家人爬山也要注意風險！」**（私揪非社團行程同樣不可輕忽風險管理）。

## 3. 領隊實務三大血淚案例摘要（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.26–28`）
完整經過與避坑檢核已彙整至 [撤退決策、迷途與待援應變失誤](../lessons/retreat-and-navigation-emergency-pitfalls.md)：
1. **案例一：大霸西北稜遲歸 2 天（P.26）** — 因颱風臨時改線、僅有 3 年前舊紀錄、連日大雷雨 D2 即延誤卻未撤退，動用 2 天預備天且差點斷糧 → **不該倉促更改路線、長天數慎選季節、應該鼓起勇氣撤退**。
2. **案例二：三分子古道迷途（P.27）** — 天氣惡劣下順不清路跡腰繞並輕信布條路標下溪谷，傍晚無訊號迫降 → **不可輕率下溪谷、檢視隊伍組成與圖資熟悉度、布條與路標不是安全保障**。
3. **案例三：能高安東軍搭直升機（P.28）** — 隊員扭傷無法走，依消防建議爬回稜線等直升機兩天因天候未飛，僅帶外帳差點冷死 → **不應該在爛天氣於稜線待援、高山不應該只攜帶外帳、走路要小心**。

## 4. 知識累積與登山三層次（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.29–30`）

### 4.1 推薦閱讀與資料來源（P.29）
- **文史類**：台大山社出版書籍（如《丹大札記》）、鄭安睎學長書籍（如《台灣最後秘境》）、楊南郡翻譯系列（如《生蕃行腳》）、李瑞宗書籍（如《北坑溪古道大系》）、吳永華與玉管處出版品等。
- **工具類**：《登山聖經》、《台灣登山史》全套、輕量化登山書籍、國內外登山技術與裝備網站／YouTube 頻道等。

### 4.2 爬山的三個層次（P.30）
1. **用體力爬山**（最基礎層）
2. **用腦爬山**：累積登山技術、安全、糧食、裝備知識，以及山林生態、歷史、產業、文化、政治等知識。
3. **用心爬山**（最高層）：運用知識、反思與行動，深化人與自然、土地的關係。
