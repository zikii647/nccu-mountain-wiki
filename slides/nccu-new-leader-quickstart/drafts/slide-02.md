# 開隊第一關：隊伍分級、資格與籌備期

| 隊伍分級 | 路線天數與條件 | 誰能開隊 |
| :--- | :--- | :--- |
| **D 級** | 3 天以下之路線 | 領隊；預備領隊（原則配輔領） |
| **C 級** | 3–5 天，或 ≤3 天含危險地形 | 領隊；預備領隊（**必配輔領**） |
| **B 級** | 6–8 天之路線 | 具對應經驗之正式領隊 |
| **A 級** | 9 日以上之路線 | 具對應經驗之正式領隊 |

- **嚴禁越級**：依自身帶隊經驗開隊，非具領隊／預備領隊資格者不得開隊
- **預備領隊免輔領例外**：(1) 一日山岳活動；(2) 具 **2 次以上過夜隊**經驗且經**安全委員一致同意**，可獨立開 D 級過夜隊
- **籌備時程**：**至少一個月前**啟動開隊工作（實務參考：武陵提前 3 個月、南湖提前 2 個月）
