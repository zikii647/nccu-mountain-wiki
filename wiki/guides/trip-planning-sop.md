# 登山計畫書撰寫與行前準備 SOP

> 本頁整理自政大登山隊高嚮訓練課講義（講者：黃子豪，2023/05/10；來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.13–21`），作為本 Wiki 審查與撰寫計畫書之核心基準。

## 1. 資料蒐集與擇定路線（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.14`）
- **核心原則**：**「挑選路線應優先考量風險與自身能力，而非自己想去的地方或是美景等因素！」**
- **能力圈評估**：確認自身能力圈（管理風險的能力），區分能力圈內的 A 路線、邊緣具挑戰性的 B 路線，以及超越自身能力範圍的 C 路線。
- **立體山域認識**：從**點、線、面、時間尺度**建立對山域的認識，辨別既存風險；切記「傳統路不一定安全，非傳統路不一定危險」。
- **推薦圖資與文史工具**：地圖產生器＋台灣百年歷史地圖、航照空拍、台大圖書館網路老照片資料庫，平時多看他隊行程紀錄。

## 2. 行程規劃與風險評估（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.15–17`）
- **行程表必備元素**（P.15）：
  - 到登山口的交通方式。
  - **起床、出發、休息、午餐、到營地的時間**。
  - 高度變化、里程數。
- **時間估算與難度控管原則**（P.15）：
  - 透過行程安排控制難度：**天數、人數、交通、預備天**都很重要。
  - **輕重裝應有不同時間估計**，針對不同**植被、地形**亦同。
  - **蒐集具有完整資訊、且「行程相似」的紀錄**（切勿拿快腳或騎車紀錄直接套用重裝大隊）。
  - 路況不明的路段，可搭配已知路線以增加應變性。
- **四大行前風險檢核點**（P.16）：
  1. 迷途風險：路況不明、事前地圖紀錄準備不足、天氣、植被。
  2. 地形風險：**腰繞路線經常會有崩塌，大雨過後也要小心**。
  3. 生物風險：透過紀錄與季節預估蜂、恙蟲、硬蜱等。
  4. 環境生理風險：缺水、失溫、中暑須一併考量與預防。
- **行前做足準備**（P.17）：
  - 撰寫詳細的計畫書與應變、醫療計畫，並與留守保持聯繫。
  - 針對不同風險準備適度裝備（如技術安全裝備）。
  - **「隊員應該也要瞭解狀況，而不是只當跟屁蟲」**。
  - 山下的時間應一併提升體力與登山知識。

## 3. 應變計畫三層次與範例（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.18–19`）

| 層次 | 撰寫要求（P.18） |
| :--- | :--- |
| **撤退計畫** | 規劃有撤退需要時的安全下山路線；**以時間、容易出事的地點為分際**；**長天數行程「每天」都要規劃**。 |
| **行程調整計畫** | 以情境規劃如何調整行程；以時間、地點為參考基礎；**經常使用在有單攻行程時，也要考量拆隊**。 |
| **醫療計畫** | 針對不同傷勢、高山症、失溫等研擬具體應變。 |

### 應變計畫優良範例參考：關門七彩湖（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.19`）
- **逐日撤退計畫寫法範例**：
  - D1：如產業道路遇無法繞過之崩塌 → 原路回撤；行車無法到 H680m 行車終點 → 視距離決定是否用踢的。
  - D2：原路回撤關門休息站，隔日下山。
  - D3：馬太鞍溪溪水暴漲 → 找安全處紮營，觀察一晚如未消退則原路回撤；**水深低於腰 → 考慮架繩通過**；**水深及腰或以上 → 考慮原路回撤**。
- **易迷途路段清單寫法範例**：依天數明確列出每個轉折點的辨識特徵與方向（如「D2 古道北繞過興魯郡山後 → 往西北稜線續行」、「D3 古道過三大溪溝處 → 跟緊獵路、觀察路跡，第二大溪溝高繞」、「D3 下到馬太鞍溪後 → 先去探上稜的路，水不大先過溪」、「D4 過了瓷器碎片平台後 → 古道微往偏北之字繞上主稜，而非往南的舊砍痕」、「D5 最低鞍部 → 抓緊方向」）。

## 4. 糧食、水資源與器材計畫（來源：`登山計畫與領隊實務（子豪學長）.pdf_｜P.20–21`）

### 4.1 糧食與水資源（P.20）
- **水源計畫**：
  - 列出**每天可取水的點**，並標明**是否穩定**。
  - 規劃**缺水時的因應**方案。
  - 若有背水需求，明確計算需要的總量（**公水＋私水**）。
- **糧食計畫**：
  - 原則：營養、方便、廚餘少；多樣化、輕量。
  - **長天數行程後面食物份量要增加**（因應熱量消耗與食慾恢復）。
  - 須搭配器材計畫（鍋具、爐頭、瓦斯量）共同安排。
- **垃圾與廢水處理**：食材盡量減少垃圾與廚餘；思考節水與不浪費、避免過度污染環境；生火考量。

### 4.2 器材計畫（P.21）
- **公裝**：
  - **帳篷／外帳要依據行程挑選**（高山環境不可只攜帶外帳，見 P.28 案例）。
  - 鍋具、爐具、瓦斯；技術安全裝備。
- **私裝**：
  - **最容易產生問題的項目：保暖衣物**（開隊務必落實裝檢！）。
  - **小背包（攻頂包）帶與不帶**須依行程特性事前評估。

## 6. AI 安全提醒／補充
> [!TIP] AI 安全提醒／延伸建議（非原始投影片記載）
> 1. **計畫書必補留守量化標準**：撰寫應變與留守章節時，建議除了「保持聯繫」之外，明確寫定「每日最晚回報時間」與「逾時未回報多久由留守人啟動通報（例如 119／國家公園）」的明確時間軸，避免留守人無所適從。
> 2. **預備天須同步配置預備糧**：若依 P.15 規劃了 1–2 天預備天，糧食計畫務必同步備妥對應天數的免煮／易煮預備糧（參見 P.26 大霸西北稜用到 2 天預備天差點斷糧之案例）。
